## Цель и баллы
- Цель: сравнить качество сегментации людей в COCO val2017 при раннем и позднем слиянии RGB+D.
- Баллы: 2 части, по 5 баллов каждая (итого 10).

## Часть 1 — Early Fusion (5 баллов)
- Реализовать и обучить модель раннего слияния [UNetResNet50RGBD](./src/models/unet_rgbd.py).
- DoD: обучение без ошибок, валидируемая mIoU ≥ 75.75%.
- Допускается своя реализация, если обучается и достигает требования по метрике.

## Часть 2 — Late Fusion (5 баллов)
- Реализовать и обучить модель позднего слияния [UNetResNet50LateFusion](./src/models/unet_late_fusion.py).
- DoD: обучение без ошибок, валидируемая mIoU ≥ 76.65%.
- Допускается своя реализация, если обучается и достигает требования по метрике.

## Подготовка данных
```bash
python seg/tools/download_coco_mini.py
python seg/tools/prepare_coco.py
python seg/tools/predict_depth_dpt.py
```
- После выполнения доступны сплиты `train_labeled500`/`val`/`test` и глубина для тех же изображений.
- Чекпоинты и глубина сохраняются в `seg/data/coco/...`.
- Используйте эти скрипты и полученные ими сплиты/глубину (хотя можете юзать какой нибудь anydepth, тут ок).

## Структура проекта
- `configs/` — конфиги обучения (`unet_rgb.json`, `unet_rgbd.json`, `unet_late_fusion.json`).
- `src/datasets/` — общий датасет `PersonSegmentationDataset` с поддержкой глубины.
- `src/datamodules/` — `CocoPersonDataModule` для Lightning.
- `src/models/` — реализации UNet (RGB, early fusion, late fusion).
- `src/person_seg_module.py` — LightningModule с метриками и оптимизацией.
- `tools/` — утилиты загрузки, подготовки и расчёта глубины без параметров.
- `notebooks/` — `person_segmentation_with_depth.ipynb` (обучение всех вариантов).
