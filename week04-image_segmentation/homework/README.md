# Домашнее задание: сегментация людей

Данное домашнее задание является такой advanced альтернативой остновной домашки по сегментации.

Идея домашки: добиться повышения качества модели сегментации используя дополнительный контекст - глубину изображений. Ваша задача научится основам обучения модели сегментации на RGBD данных :)

Задача максимально упрощена, часть кода перенесена из семинара сюда, чтобы вам не пришлось делать копипасты самим. От вас требуется реализация моделей и эксперименты т.ч. побился требуемый бейзлайн.
Точка входа в домашку - ноутбук notebooks/person_segmentation_with_depth.ipynb

Тем не менее постановка задачи довольно общая, и стоит идти в ее решение только если чувствуете в себе достаточно силы)

## Цель и баллы
- Цель: сравнить качество сегментации людей в COCO val2017 при раннем и позднем слиянии RGB+D.
- Баллы: 2 части, первая на 5 баллов, вторая на 10 баллов.

## Часть 1 — Early Fusion (5 баллов)
- Реализовать и обучить модель раннего слияния [UNetResNet50RGBD](./src/models/unet_rgbd.py).
- DoD: обучение без ошибок, валидируемая mIoU ≥ 75.75%.
- Допускается своя реализация, если обучается и достигает требования по метрике.

## Часть 2 — Late Fusion (10 баллов)
- Реализовать и обучить модель позднего слияния [UNetResNet50LateFusion](./src/models/unet_late_fusion.py).
- DoD: обучение без ошибок, валидируемая mIoU ≥ 76.65%.
- Допускается своя реализация, если обучается и достигает требования по метрике.

## Что сдавать в LMS
- две тетрадки (по одной на каждую часть) с аутпутами, в которых есть явно цифирка с качеством финальной модели
- файлики с реализацией моделей (один для early fusion, один для late fusion)

## Подготовка данных
```bash
python tools/download_coco_mini.py
python tools/prepare_coco.py
python tools/predict_depth_dpt.py
```
- После выполнения доступны сплиты `train_labeled500`/`val`/`test` и глубина для тех же изображений.
- Чекпоинты и глубина сохраняются в `data/coco/...`.
- Используйте эти скрипты и полученные ими сплиты/глубину (хотя можете юзать какой нибудь anydepth, тут ок).

## Структура проекта
- `configs/` — конфиги обучения (`unet_rgb.json`, `unet_rgbd.json`, `unet_late_fusion.json`).
- `src/datasets/` — общий датасет `PersonSegmentationDataset` с поддержкой глубины.
- `src/datamodules/` — `CocoPersonDataModule` для Lightning.
- `src/models/` — реализации UNet (RGB, early fusion, late fusion).
- `src/person_seg_module.py` — LightningModule с метриками и оптимизацией.
- `tools/` — утилиты загрузки, подготовки и расчёта глубины без параметров.
- `notebooks/` — `person_segmentation_with_depth.ipynb` (обучение всех вариантов).
