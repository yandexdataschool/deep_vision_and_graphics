# Детекция через обучаемые точки выборки

[Ноутбук](notebooks/detection_deformable_60min.ipynb) · [Пояснения и статьи](ADDITIONAL_NOTES.md)

Декодер по принципам Deformable DETR: обучаемые точки выборки, уточнение боксов и признаки нескольких разрешений. Весь код находится в ноутбуке. Сохранённые результаты доступны без повторного обучения.

## Содержание

1. Состояние query, positional embedding, опорный бокс и dense attention.
2. Билинейная интерполяция, градиент по координатам, смещения и веса точек.
3. Использование предыдущего бокса при следующей выборке признаков.
4. C3/C4/C5 при одинаковом числе точек.
5. Абляции, AP, время вычислений и обобщение на реальных изображениях.

В дополнении — L1/GIoU, нормировки loss, no-object и численные проверки. Отдельные PNG находятся в [figures](figures/).

## Запуск

Python 3.12. Команды выполняются из этой папки:

```bash
python3.12 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
python tools/start_notebook.py
```

Jupyter откроется на `127.0.0.1:8889`. Для повторения опытов выбрать **Restart Kernel and Run All Cells**.

Первый запуск скачивает COCO128 (~7 MB) и ImageNet-веса ResNet18 (~47 MB), вычисляет признаки и обучает декодеры на CPU. Backbone заморожен. Каждый вариант обучается 600 шагов с batch 8; используются три seeds. Пять вариантов на двух наборах дают 30 обучений. Время зависит от компьютера.

Данные лежат в `data/`, признаки и checkpoints — в `runs/detection60/`. Повторное выполнение загружает совместимые checkpoints по конфигурации и хешу кода модели.

Запуск из терминала:

```bash
python tools/execute_notebook.py
```

## Условия экспериментов

| Вариант | Выборка признаков | Бокс для следующего чтения |
|---|---|---|
| `global` | Все 48 позиций C5 | Геометрия не используется reader |
| `fixed` | Шесть фиксированных относительных смещений на голову, C5 | Начальный |
| `learned` | Шесть обучаемых смещений на голову, C5 | Начальный |
| `refine` | Шесть обучаемых смещений на голову, C5 | Предыдущий предсказанный |
| `multi` | По две точки на C3/C4/C5 на голову | Предыдущий предсказанный |

Во всех вариантах box heads уточняют боксы по слоям. Feedback меняет только геометрию следующей выборки. В `fixed` начальные боксы и веса точек продолжают обучаться.

- **Shapes:** 192 train / 64 validation, один класс, 0–4 объекта.
- **COCO128/person:** 96 train / 32 validation, включая изображения без людей. Собственный split из COCO train2017; YOLO-аннотации не содержат crowd metadata.

AP считается через COCOeval по всем 32 кандидатам, без NMS и порога уверенности. Порог 0.3 используется только на рисунках. Это учебный опыт, а не результат на официальном COCO val2017.

В сохранённых запусках добавление уровней увеличило AP50 на Shapes с 0.195 до 0.769. Отдельного прироста от обучения смещений и feedback при этом бюджете не получено. На реальных данных заметен разрыв train/validation.
